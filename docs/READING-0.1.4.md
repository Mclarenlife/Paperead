# Paperead 0.1.4：阅读与校对工作流

本次实现已确认清单中的第 7–11 项，延续 0.1.3 的资料库和任务数据。

## 7. 阅读导航

- 阅读器右上角查找按钮打开「导航」，内含全文查找、目录和书签；Ctrl/Cmd+F 直接聚焦查找。
- 原文查找覆盖当前文献全部提取页，忽略大小写和换行空白。点击结果跳转到对应页并标示匹配文字；Enter / Shift+Enter 浏览下一个或上一个。当前译文或重排版本按完整渲染文档查找。
- PDF 使用文件自带的目录；无法解析的目录项不允许跳转，无目录的 PDF 显示空态。Markdown 结果根据标题生成目录。
- 为原文页或已完成结果添加命名书签，可跳转和删除。每篇上限 1000 个，搜索最多显示 5000 处匹配。
- 分别记住原文页和各 AI 版本的相对滚动位置，下次打开恢复上次的来源及版本。关闭阅读器前等待位置写入；结果版本删除后清理对应位置和书签。

扫描页仍需要 OCR；本次文献内查找不包含跨资料库的正文索引。

## 8. 批注管理

批注卡可编辑评论和颜色，引用内容及位置不变。支持搜索引用与评论，按原文、译文、重排或当前版本筛选；当前文献筛选后的批注可导出为 Markdown 汇总，包含来源、页码或全文、版本名称、引用、评论、颜色和日期。原有回收站和转为笔记功能保留。

## 9. AI 结果与校对

- 「校对当前结果」或任务卡「校对」打开 Markdown 编辑和预览，保存为新的修订版本。
- 原版本的文本、批注和位置保持不变，修订版本可另外批注；不迁移旧批注以免偏移错位。
- 每个版本可命名或删除；运行中的版本须先暂停。删除前明确说明会清理该版本的批注、书签和校对草稿；其他结果、已生成的重排及独立笔记保留。
- 校对草稿另存本机缓存，写入失败保留内容。关闭编辑器、离开页面或关闭原生窗口时提供保存、导出、保留或放弃选项。重新打开该原版本的校对界面可恢复草稿。
- 彻底删除文献后清理其结果草稿，避免孤立草稿阻塞备份；移入回收站仍保留草稿。

结果历史中的「使用当前配置重新处理」仍是重新请求 AI；手动校对保存不调用 API。

## 10. 从译文或校对稿重排

在 AI 助手的「重排输入来源」选择原文或任一已完成结果，再开始重排。推荐操作：翻译 → 校对并保存新版本 → 选择该校对版本 → 重排。

任务保存选中版本的完整 Markdown 输入快照和来源名称，模型提示明确处理这个输入、保留其语言和内容。若输入包含双语引用，保留原文引用及译文。删除父版本后，已经生成的重排仍可阅读，重试也使用保存的输入快照。内部继续按预算分批请求、合并成一个 Markdown 文档。

## 11. 多 API 配置

偏好设置支持新建、命名、修改、切换和删除配置，最多 50 套。每套包含协议、地址、模型、目标语言、原文对照默认值、超时、流式、并行数、批次预算、输出上限和密钥保存偏好。已有单套配置自动迁移为默认配置。

密钥仍使用系统凭据或会话内存，绝不写入配置档案。相同协议与规范化地址共用该端点的密钥；不同端点隔离。删除档案保留凭据，以免影响共用的其他模型配置；「清除密钥」可显式清除。切换时提醒尚未保存的配置修改，旧任务继续使用自己的配置快照。

Windows 可保存到系统凭据存储；浏览器和 Android 的密钥仍只在当前会话有效。配置档案保存在本机设置，不进入资料库 ZIP 备份。

## 数据兼容

IndexedDB 仍沿用原资料库与 schema 2，仅在 Paper / Job 中增加可选字段。升级保留原文、笔记、批注和任务。

完整备份升级为格式 3，保留校对 Markdown、版本名称、来源、书签、阅读位置和回收站状态；继续接受格式 1 / 2。旧应用拒绝格式 3，避免还原时静默丢弃校对内容。备份前须先保存或明确放弃笔记及校对草稿；草稿不作为正式结果打入备份。
