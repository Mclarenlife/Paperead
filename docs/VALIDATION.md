## 已通过

- TypeScript 严格类型检查。
- Vite 生产构建；阅读器、PDF、设置、Markdown 与 DOCX 按需加载。界面字体、PDF CMap、标准字体和解码资源已本地化。
- 12 项 Vitest 测试：初始化幂等、删除文献保留笔记、完整备份往返、坏备份无写入、版本拒绝、会话密钥按地址隔离、API URL 约束、四种协议请求、响应解析与截断检查、文本分块、任务失败恢复、在途取消。
- 8 项 Playwright 流程：
  1. 生成并导入真实两页 PDF，去重、渲染、翻页、划词高亮、评论、刷新持久化。
  2. 搜索、取消收藏、新建与重命名文献集、Markdown 编辑与导出、刷新保留。
  3. 配置 AI、验证实际发出的兼容协议请求（服务响应被测试拦截器模拟）、完成翻译、译文批注、导出与刷新恢复。
  4. 完整 ZIP 备份、原始 PDF 字节比对、删除后恢复、重新渲染。
  5. HTML / TXT / DOCX 下载与内容校验，实际解包 DOCX 检查文档内容。
  6. 损坏 PDF 拒绝，资料库无半成品记录。
  7. AI 重排遇到 HTTP 429 后保留状态，恢复未完成任务并成功显示结果。
  8. 390px 手机文献库与笔记界面无横向溢出，暗色主题与页面背景持久化。
- 桌面与手机截图人工检查；PDF 文本层与高亮位置检查；首次页面无 JavaScript 错误。
- Windows x64 Release：Rust 1.98.1、Cargo 1.98.1、Visual Studio Build Tools 17.14.37614.0、MSVC 14.44.35207、Windows SDK 10.0.26100.0；Cargo.lock 已锁定依赖，使用 `--locked` 构建成功。
- NSIS 安装包生成成功（17,533,978 字节），中文 / 英文安装配置，安装器静默安装到独立测试目录成功，退出码 0。
- 从安装目录启动真实 Windows 程序，通过 WebView2 152 的本机调试接口验证打包界面、真实 PDF Worker 与文本层、翻页、批注持久化、Markdown 预览与刷新保存；JavaScript 错误数为 0。查看了原生截图。
- 原生 HTTP 插件完成 3 次对本机模拟服务的真实 POST 请求，包括连接测试和两页 PDF 的翻译任务；无需浏览器 CORS 放行，没有调用外部模型。
- 使用安装包自带卸载器清理测试安装，退出码 0；主程序只依赖 Windows 系统 DLL，无额外 VCRUNTIME DLL 依赖。

测试生成的 PDF、导出文件和截图保存在 `.tmp`，失败 trace 保存在 `test-results`，均为可重新生成的开发产物。原生验证脚本为 `scripts/smoke-windows.mjs`，本次报告为 `.tmp/windows-smoke-report.json`。测试使用独立 WebView2 资料目录，调试端口不写入发布配置。

## 尚未验证 / 尚未实现

- 尚未使用用户真实 API Key 调用任何外部模型。当前测试验证请求协议、错误处理与任务状态，不代表翻译准确度评测。
- macOS / Android / iOS 尚未生成安装包；Windows 当前验证环境为 Windows 11，尚未在 Windows 10 或 ARM 设备验证。
- 原生系统文件选择 / 保存对话框尚未完成自动化验证；本次原生 PDF 导入通过应用已有的文件输入控件触发。缺少 WebView2 的全新机器上的引导下载流程尚未验证。
- Android / iOS 选择器、保存器、HTTP 取消、键盘、生命周期、WebView 存储持久性与真实设备内存占用仍需真机验证。
- 不包含 OCR、专业版面恢复、云同步、系统密钥链、安装包签名、专业 DOCX 公式转换、原始 PDF 内嵌批注。
- 100 MB / 1500 页的输入限制是保护边界，不表示该规模已完成性能压测。
