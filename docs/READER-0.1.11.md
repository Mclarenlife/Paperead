# Paperead 0.1.11 阅读工作区

阅读器保留上方工作区标签页和系统窗口控制，下方只有一行文献工具栏。不再重复展示论文标题、作者和年份；完整标题仍可在标签页查看，元数据仍可通过编辑按钮管理。

## 视图

- 原文：显示可连续下滑的 PDF，保留页码跳转、缩放、全文查找、目录和书签。
- 译文：显示连续 Markdown 翻译结果，支持流式预览、校对、版本和导出。
- 对照：桌面左右显示 PDF 和译文，手机上下显示；两个窗口各自滚动。进入对照时收起辅助侧栏，需要批注或 AI 操作时可重新展开。

在任一窗口选中文字时，批注绑定该窗口的来源、结果版本和页码。PDF 坐标以所选页面为基准，不受当前工具栏页码或另一窗口滚动的影响。原文和译文分别保存阅读位置。

## 连续 PDF

每份 PDF 只创建一个 PDF.js 文档实例。为整篇论文建立页面占位，仅为接近可视区域的页面创建 canvas 和文本层；远离视口后释放 canvas 和文本层。页面尺寸按实际 PDF 更新，大页面的绘制像素数有上限。

当前页随下滑更新。页码、搜索、目录、书签和批注定位均滚动到目标页面；缩放和侧栏宽度变化保留所在页及页内位置。页内阅读记录沿用原有数据结构，可继续读取旧版位置。

## 移除智能重排

删除模式切换、AI 助手中的智能重排创建与输入来源选择，以及普通历史重排任务的继续 / 重新处理入口。保留已有结果、批注、书签和导出能力。存储类型继续兼容旧版备份及扫描件识别结果，扫描件识别功能保留。

## 验证

`tests/e2e/continuous-reader.spec.ts` 使用 24 页、包含横向页面的真实 PDF，检查下滑、按需绘制、跨页批注、缩放和宽度变化、重开定位、原译文独立滚动与手机对照布局。既有阅读流程测试覆盖搜索、目录、书签、版本与批注；完整浏览器回归继续覆盖导入、翻译、OCR、备份和笔记。
