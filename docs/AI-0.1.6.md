# 0.1.6 翻译、排版与公式修复

用户反馈：每批次首字等待过长、分段不准确、标题没有 Markdown 层级、公式缺少 LaTeX 或识别错误。当前使用模型为 `deepseek-v4-flash`。

## 已修复的机制

- DeepSeek V4 默认开启高强度思考，旧版没有传递关闭参数。新任务默认发送 `thinking.type=disabled`；Responses 和 Anthropic 格式使用对应参数。设置里可选低／高强度思考或服务商默认，配置、任务和备份均保留该选择。未知模型不收到 DeepSeek 专用参数，不自动更换用户的模型或地址。
- 流式进度区分排队、等待响应、思考、非流式正文等待和正文输出。思考内容不会进入文献。首个正文片段立即显示，重复思考事件不会持续触发重绘；记录每批次排队、首字和总耗时，任务卡片可见首字耗时。
- 长文首批按完整段落缩短至约 1500 字符；后续仍按设定预算跨页合并，保留共享并发队列、暂停和断点续传。短文保持一次请求，不改成逐页或逐段发送。
- 后续并行批次已经返回时可独立预览，不再被前面的慢批次完全挡住。完成后按原文顺序合成一份 Markdown；预览标签不会写进结果、导出或批注。
- PDF 文本提取版本升级为 3：按坐标重建文字行，识别双栏空隙和跨栏标题，结合字号、编号、行距及缩进恢复标题和段落，合并软换行断词，恢复可明确识别的上下标。原始 PDF 和文字选择坐标保留。
- 新任务按需升级旧 PDF 提取文本。已有 OCR／视觉解析页面始终优先，不会因为另一页需要升级就被重新提取覆盖；现有任务、校对、批注不会被修改。
- 公式、表格和代码块不会按字符预算从中间切断；行内公式也作为完整单元处理。超长结构可能超过设置的批次字符目标，以保持结构完整。
- 强化标题、段落、数学和表格约束；规范 `#`／`##`／`###`，将 `\(...\)`、`\[...\]` 和独立 equation／align／gather 环境转换成阅读器支持的数学语法，保留代码与原文引用。
- 翻译中的已有 LaTeX 使用占位标记发送，最后由本机原样还原，避免模型改写变量、上下标和分式。缺失或重复公式标记会拒绝将该批次标记为完成，已完成批次保留。原文对照的译文标题级别也在本机按源段落恢复。
- 视觉识别默认覆盖所选范围内含文字的页面，修复“页面有文字就不识别公式”的使用陷阱。已知不支持图片的 DeepSeek 文字型号会在发送请求前说明原因。

## 升级后的使用方法

1. 关闭旧版，安装 `release/Paperead_0.1.6_x64-setup.exe`。资料库沿用原应用标识，无需重新导入。
2. DeepSeek V4 原有配置自动采用关闭思考策略；第三方网关若拒绝此参数，在“请求与性能设置 → DeepSeek 思考模式”选择“服务商默认”。流式输出保持开启。
3. 在原有翻译／重排任务上点击“使用当前配置重新处理”，让新提取和分段覆盖整篇新版本。仅继续旧任务会沿用旧的分段快照。
4. 原 PDF 的复杂分式、矩阵、扫描公式识别不准时，先选择支持图片的视觉模型，在“扫描件与版面识别”中选视觉模式和相应页码，完成后再切回文字模型进行全文翻译。`deepseek-v4-flash` 本身不支持图片输入；是否有视觉型号权限以所用服务商为准。
